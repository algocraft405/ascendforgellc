# Ascendforge LLC

Retail ecommerce website for **Ascendforge LLC**, a sports-gear shop based in Oklahoma City.

Inspired by the catalogue layout of [Glasswizard](https://glasswizard.vercel.app): focused inventory, honest copy, and a warehouse-first storefront.
